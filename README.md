# Robot Rhythm UI

Landscape mobile UI in Unity.

Open `Assets/Scenes/MainMenu.unity` for the connected menu and game flow.

Play opens the level cards for Tutorial, City, Desert, Ice, and Mountain Range. Pause offers Resume, Level Selector, How to Play, Retry, Scoring, Settings, and Main Menu.

The HUD shows score, accuracy, stars, combo, and song time remaining. Completed scored levels save best score and accuracy. Tutorial does not save records. Results appear over the animated navy menu background.

Skins opens the robot selector. Complete levels to unlock their skins, or perfect every configured scored level for Prismatic Gold. Space is prepared for a future level and is not assigned yet. Normal unlock rules are enabled; local preview controls are off.
