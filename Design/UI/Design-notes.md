# UI specification

Landscape, 1280 x 720 reference frame, fitted inside the device safe area.

Home, Routes, Controls, Settings, and a static level placeholder. Touch input affects menu navigation and selections only.

Cream backgrounds, angled panels and buttons, coral primary actions, gold selections, navy structure, and teal logo panels. The original logo's navy shadow remains visible on teal. Its two rows slide in with a slight overshoot and share a gentle idle drift. Reduced Motion stops the animation.

Route artwork and the level view use crossed placeholder fields. No gameplay state, movement, scoring, or results appear.
